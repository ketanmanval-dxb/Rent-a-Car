## Shared contracts

- Server modules export typed functions; app pages and server actions call them. **db** publishes function signatures in Messages as they land.
- Money: integer fils. Time: `timestamptz` UTC; periods are `tstzrange` `[start,end)`; branch has an IANA `timezone`.
- Dev server: **app** runs `pnpm dev` on port 3000. **qa** runs e2e against `pnpm build && pnpm start -p 3100` (`PLAYWRIGHT_BASE_URL=http://localhost:3100`) to avoid clashing.
- DB: `driveeasy_dev` for dev/seed; `driveeasy_test` for automated tests only (tests may reset it).
